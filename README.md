> 基于桌面成果包《智选云 AI 电商在线售货系统-完整成果包》实现的**功能完整的电商在线销售系统静态网站**。
> 功能范围取自用例图（图 3-1 / 3-2 / 3-3）、功能结构图（图 3-5）与系统功能清单；
> 数据模型取自核心数据模型图（图 4-8 ERD）；订单流转取自订单状态图（图 4-7）与下单支付时序图（图 4-10）。
> **零后端、零构建、零外部依赖**——双击 `index.html` 即可在浏览器直接运行。

---

## 一、如何运行

| 方式 | 操作 |
|---|---|
| 直接打开（推荐） | 双击 `index.html`，或使用浏览器打开该文件（`file://` 协议即可） |
| 本地服务（可选） | 在本目录执行 `python -m http.server 8080`，访问 http://127.0.0.1:8080 |
| 部署上线 | 把 `index.html` 与 `assets/` 原样上传到任意静态托管（Nginx / OSS / GitHub Pages / COS / Vercel 等）即可，无需构建 |

> 说明：站点不使用 `fetch` 请求任何外部 JSON（避免 `file://` 下被 CORS 拦截），全部数据内嵌于 `assets/data.js`；
> 用户态数据（登录、购物车、订单、地址、收藏、评价）保存在浏览器 `localStorage`，刷新与重启浏览器均保留。
> 若浏览器禁用 `localStorage`，会自动降级为内存存储，页面仍可正常演示。

|---|---|---|
| 首页与品类导航 | `#/` | Hero、18 个品类入口、精选商品、AI 智能选品推荐位、**一键体验**快捷登录 |
| 商品浏览 | `#/products` | 21 个商品卡片网格，销量/价格/上新排序 |
| 搜索筛选 | `#/products` | 关键词搜索（标题/规格/属性）、分类树筛选、**属性 facet 多选筛选**、价格区间、四种排序 |
| 商品详情 | `#/product/:id` | 大图(emoji+渐变)、SKU 规格切换（实时改价与库存）、数量增减、加购/立即购买/收藏、**AI 智能组货建议** |
| 购物车 | `#/cart` | 增删改数量、删除、实时小计与合计、去结算 |
| 下单结算 | `#/checkout` | 收货地址选择/新增、商品清单、优惠券抵扣、支付方式选择、提交并模拟支付 |
| 订单管理 | `#/orders` | 状态分栏（全部/待支付/待发货/待收货/已完成/已关闭），去支付、取消、确认收货、评价 |

| 登录注册 | `#/login` | 手机号+密码登录/注册，角色区分（消费者/商家/管理员），登录后回跳原页面 |
| 商家后台 | `#/admin` | 经营看板、商品管理（**按品类 Schema 动态生成发布表单**）、订单管理（发货/退款）、品类 JSON 导入 |
| AI 智能客服 | 右下角浮窗 | 意图识别 → 知识库 RAG / 业务工具查订单 → 置信度与**降级**标记；含快捷提问 |

### 三项 AI 能力（与成果包设计一致）

| 能力 | 实现 | 降级契约 |
|---|---|---|
| 智能客服 | 关键词/意图分流：知识咨询走知识库 RAG-lite，业务事实（订单/物流）走受控工具查询真实本地数据 | 未命中知识库时返回 `degraded=true` 与转人工话术 |
| 智能选品 | 行为召回（浏览记录所在品类）+ 评分/销量精排 + 冷启动兜底（按评分销量排序） | 召回不足时自动回落到热门排序 |
| 智能组货 | 预置搭配方案（理由 + 组合价 + 毛利 + 场景），并做库存/价格/毛利四维校验 | 组合不完整或库存不足时 `degraded=true`，降级为单品推荐 |

所有 AI 响应均携带 `degraded` / `degradeReason` 字段，**AI 异常不阻断交易主流程**（非功能需求 NFR-06/07）。

## 四、数据模型（对应图 4-8 ERD）

`assets/data.js` 内嵌并模拟：

- **品类**：`t_category`（5 个一级 / 12 个叶子品类，含父子层级、path、isLeaf）+ `t_category_attr`（属性 Schema：品牌/颜色/存储/尺码/材质/肤质/功效/口味等，标记 `isRequired` 与 `isFilterable`，直接驱动商品筛选 facet 与商家动态发布表单）
- **商品**：`t_product` → `t_sku`（21 个商品、40+ SKU，含规格、售价、市场价）→ `t_inventory`（可用库存，下单锁定、取消/退款释放）
- **用户**：`t_user`（角色 consumer/merchant/admin、会员等级）+ `t_user_profile`（昵称/性别/生日）+ `t_user_behavior`（浏览行为，供选品召回）
- **交易**：`t_order`（状态机 `待支付10 → 已支付20 → 待发货30 → 已发货40 → 已完成50`，含 `已关闭60/已退款90`）+ `t_order_item` + `t_payment`（渠道、交易号、支付时间）
- **AI**：`t_knowledge_chunk`（客服知识库 7 条）+ `t_bundle`/`t_bundle_item`（4 套组货方案）+ `t_conversation`/`t_message`（会话持久化）

**库存一致性**：下单即锁定库存（可用量递减），取消订单与退款自动释放，支付成功后触发商家履约发货。

## 七、已验证的业务闭环

1. 浏览首页 → 品类导航 → 商品列表（搜索/分类/属性/价格/排序筛选）
2. 商品详情（切规格改价改库存）→ 加入购物车 → 购物车改数量
3. 登录 → 结算（选地址、优惠券抵扣）→ 提交订单**锁定库存** → 模拟支付 → **扣减库存并触发履约**
4. 我的订单：支付/取消（释放库存）/确认收货/评价 → 状态机全程贯通
5. 用户中心：资料编辑、地址管理、收藏、评价、AI 推荐
6. 商家后台：看板统计、按品类 Schema 动态发布商品、发货/退款、品类 JSON 导入（含非法 JSON 报错）
7. AI 客服浮窗：订单查询走业务工具、退换货走知识库、未命中走降级话术

> 以上流程已通过 jsdom 无头端到端冒烟测试，全程 0 运行时错误。
